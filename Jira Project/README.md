\# Enterprise PMO Analytics Dashboard



\## Project Overview



This project demonstrates the design and execution of an Agile/Scrum-based PMO analytics and project-tracking environment using Jira and Confluence.



The objective was to create a structured project-management environment capable of tracking project work, sprint delivery, priorities, risks, issues, and PMO reporting metrics.



\## Tools \& Technologies



\- Jira — Agile project planning, backlog management, sprint execution and reporting

\- Confluence — Project documentation, requirements, decisions and delivery documentation

\- GitHub — Project artifact and portfolio repository



\## Project Structure



The project was organized around 10 major PMO workstreams represented as Jira Epics:



1\. Project Initiation

2\. Resource Planning

3\. Financial Management

4\. Risk Management

5\. Issue Management

6\. Milestone \& Schedule Management

7\. Change Request Management

8\. Benefits Realization

9\. Executive Reporting

10\. Project Closure



Each workstream was further decomposed into user stories and detailed sub-tasks to create a structured project backlog.



\## Agile Delivery



The project follows an Agile/Scrum delivery approach.
